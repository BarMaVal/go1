Слайд 2 · Мотивация

Зачем нужен Go?

Go (или Golang) придумали в Google в 2009 году три очень уважаемых программиста. Они хотели язык, который простой как Python, но быстрый как C. Вот 4 главные причины его выучить:

⚡

Быстрый как C

Go компилируется сразу в машинный код. Программа не «переводится на лету», как в Python, поэтому работает в разы быстрее.

🧩

Простой синтаксис

Всего 25 ключевых слов. Если ты знаешь переменные, циклы и функции из Python — ты уже понимаешь 80% Go.

🔀

Встроенная параллельность

Горутины — это мини-потоки, которые пишутся одним словом go. Программа может делать 100 дел одновременно.

💼

Востребован в компаниях

Docker, Kubernetes, Twitch, Ozon, VK, Wildberries — серверы и сервисы этих компаний написаны на Go.

🛴 Аналогия, которую стоит запомнить

Python — это самокат: удобно, легко научиться, быстро поехал по двору.

Go — это электросамокат с мотором: рулить так же просто (почти те же команды), но едет заметно быстрее и везёт тебя дальше — например, на нём уже можно делать настоящие серверы и приложения.

Слайд 3 · Установка

Установка Go за 5 шагов (Windows)

  1. Зайди на официальный сайт go.dev/dl — там лежат все свежие версии.
  2. Скачай установщик для Windows с расширением .msi (например go1.22.0.windows-amd64.msi).
  3. Запусти скачанный файл и просто нажимай «Next» → «Install» → «Finish». Все настройки оставляй по умолчанию — Go сам пропишет себя в систему.
  4. Открой терминал: нажми Win + R, набери cmd и нажми Enter.
  5. Проверь, что всё получилось, командой go version.
Терминал (cmd)
C:\Users\Uchenik> go version
go version go1.22.0 windows/amd64
✅ Проверь себя

В терминале должна появиться строка вида go version go1.22.x windows/amd64. Номер версии может отличаться — это нормально, главное, что он есть.

Если вместо этого написано «go» не является внутренней или внешней командой — просто закрой окно терминала и открой новое. Windows не всегда сразу «видит» свежую программу.

macOS: скачай файл .pkg с go.dev/dl и установи двойным кликом. Или, если есть Homebrew, выполни:

Терминал (macOS)
brew install go
go version

Linux: скачай архив .tar.gz с go.dev/dl и распакуй его в /usr/local, затем добавь путь в переменную PATH:

Терминал (Linux)
sudo tar -C /usr/local -xzf go1.22.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin
go version

Установка VS Code и расширения Go

Go можно писать даже в «Блокноте», но с хорошим редактором программировать в 10 раз приятнее. Мы возьмём VS Code — он бесплатный, как и сам Go.

  1. Зайди на code.visualstudio.com, скачай VS Code и установи (снова просто жмём «Next»).
  2. Открой VS Code.
  3. Слева на панели нажми значок из четырёх квадратиков — это вкладка Extensions. Горячая клавиша: Ctrl+Shift+X.
  4. В строке поиска набери Go.
  5. Найди расширение «Go» от «Go Team at Google» (у него миллионы установок) и нажми Install.
  6. Создай файл hello.go и открой его. VS Code покажет окошко «Tools for Go are missing» — нажми Install All и подожди пару минут, пока скачаются помощники.

Слайд 5 · Первая программа

Первая программа: hello.go

Создай папку go-projects, в ней файл hello.go и напиши ровно этот код:

Go · hello.go
package main

import "fmt"

func main() {
    fmt.Println("Привет, мир!")
}

Разбор построчно

Строка кодаЧто она делает
package main «Этот файл belongs к главному пакету». Пакет — это папка с родственным кодом. main означает: из этой программы можно сделать запускаемый файл.
import "fmt" Подключаем «коробку с инструментами» fmt (format) — там живут функции для вывода текста на экран. Аналог import math в Python.
func main() { Объявляем функцию main. С неё всегда начинается выполнение любой Go-программы. Фигурная скобка открывает «тело» функции.
fmt.Println("Привет, мир!") Печатаем строку и переходим на новую линию (ln = line). Почти как print() в Python, только с «фамилией» fmt. перед именем.
} Закрываем тело функции. Забыть эту скобку — ошибка №1 у всех новичков (мы про неё ещё поговорим).
🐍 Сравнение с Python

В Python тебе хватало одной строки print("Привет"), а Go требует «рамку» из package и func main — зато программа получается самостоятельным приложением, которое можно запустить даже на компьютере без установленного Python.

Python · hello.py (для сравнения)
# весь код на Python — одна строка
print("Привет, мир!")
Слайд 6 · Команда

Команда go run — написать и сразу запустить

go run hello.go делает два дела подряд:

  • компилирует твой код (переводит в понятный компьютеру машинный код) во временную папку;
  • сразу запускает результат и показывает вывод в терминале;
  • потом временный файл тихо удаляет — в твоей папке ничего лишнего не остаётся.
Терминал (cmd)
C:\go-projects> go run hello.go
Привет, мир!

C:\go-projects>
🐍 Аналогия с Python

Это как python hello.py — написал и сразу работает. Идеальная команда для учёбы и проверки идей: поменял строчку → снова go run → посмотрел результат.

⚠️ Частая ошибка

Команду нужно запускать в той же папке, где лежит файл. Перейти в папку: cd C:\go-projects. Если написать имя файла с ошибкой, Go ответит: stat hello.go: The system cannot find the file specified.

Слайд 7 · Команда

Команда go build — собрать готовый файл

go build hello.go ничего не печатает — она молча создаёт рядом настоящий исполняемый файл hello.exe. Его можно:

  • запустить двойным щелчком мыши;
  • отправить другу в мессенджере — и программа заработает без установленного Go;
  • положить на сервер, который работает 24/7.
Терминал (cmd)
C:\go-projects> go build hello.go

C:\go-projects> dir hello.exe
 Том в устройстве C имеет метку Windows
26.03.2024  18:42         1 204 736 hello.exe

C:\go-projects> hello.exe
Привет, мир!
🐍 Аналогия с Python

Python так не умеет «из коробки»: чтобы получить .exe, нужно ставить отдельные инструменты (pyinstaller, cx_Freeze) и писать сложные команды. Go делает это одной короткой командой.

💡 Когда что использовать?

go run — пока пишешь и проверяешь код (быстро и удобно).
go build — когда программа готова и её пора запускать «по-взрослому» или отдавать другим людям.

Слайд 8 · Команда

Команда go fmt — робот-уборщик для кода

go fmt hello.go автоматически расставляет отступы, пробелы и скобки по официальному стандарту Go. Тебе больше не нужно спорить, сколько пробелов ставить — за тебя всё решит команда.

❌ ДО: кривой код
Go · hello.go
package main
import "fmt"
func main() {
// печатаем приветствие
fmt.Println("Привет")
   x:=5
        if x>3 {
fmt.Println("x больше 3")
}
}
✅ ПОСЛЕ: go fmt
Go · hello.go
package main

import "fmt"

func main() {
    // печатаем приветствие
    fmt.Println("Привет")
    x := 5
    if x > 3 {
        fmt.Println("x больше 3")
    }
}
Терминал (cmd)
C:\go-projects> go fmt hello.go
hello.go
🤖 Аналогия

Представь робота-уборщика, который ровняет твой код по линейке: разбросанные детали он аккуратно складывает в ряды. Код становится одинаково красивым у всех программистов мира — поэтому чужие программы на Go так легко читать.

✅ Совет для VS Code

В VS Code форматирование срабатывает само при сохранении: нажал Ctrl+S — и код уже ровный. Если этого не происходит, открой настройки (Ctrl+,), найди Format On Save и поставь галочку.

Слайд 10 · Синтаксис

Синтаксис: Python vs Go

PythonGoКомментарий для ребёнка
x = 5 x := 5 «В Python тип угадывался на лету, в Go мы говорим компилятору один раз — и всё»
print("Привет") fmt.Println("Привет") «Тот же print, только с фамилией fmt»
if x > 0: if x > 0 { ... } «Отступы больше не командуют — командуют фигурные скобки»

🐍 Главное отличие одной фразой

Python догадывается обо всём сам, а Go любит точность: ты явно пишешь типы и скобки — зато компилятор заранее поймает ошибку, а не программа упадёт у пользователя.

Слайд 11 · Ошибки

Три кита, на которых стоит ошибка новичка

1. Забытая закрывающая скобка }

И хорошая новость: точка с запятой в Go НЕ нужна — компилятор сам «доставляет» её в конце строки. А вот скобку закрыть обязан ты.

❌ Неправильно
Go
func main() {
    fmt.Println("Привет")
// скобку } закрыть забыли!
Ошибка
./hello.go:5:1: missing '}' in statement block
✅ Правильно
Go
func main() {
    fmt.Println("Привет")
} // вот она, родная

Приём: ставь { и } парой сразу, а потом пиши код между ними.

2. Неиспользуемая переменная = ошибка компиляции

Python просто «забыл» бы про неё, а Go строг: объявил — используй!

❌ Неправильно
Go
func main() {
    name := "Аня" // создали и... забыли
    fmt.Println("Привет!")
}
Ошибка
./hello.go:4:6: "name" declared and not used
✅ Правильно
Go
func main() {
    name := "Аня"
    fmt.Println("Привет,", name)
}

Лайфхак: если переменная нужна «на потом», используй её хотя бы так: _ = name.

3. Фигурная скобка { перенесена на новую строку

В Python так можно, в Go — нельзя. Скобка всегда живёт на той же строке, что и func / if / for.

❌ Неправильно
Go
func main()
{
    fmt.Println("Привет")
}
Ошибка
./hello.go:3:1: syntax error: unexpected semicolon or newline before {
✅ Правильно
Go
func main() {
    fmt.Println("Привет")
}

Запомни: «скобка прыгает наверх, к слову func» — как хвостик у буквы.

Уровень 1: задачи 1–4 ⭐

Разминка: вывод текста, переменные, ввод
1

«Привет, Go!» ⭐

Выведи на экран строку Привет, мир!, а на следующей строке — своё имя. В Python это были бы два print(). В Go — два fmt.Println().

Скопируй каркас из hello.go (package, import, func main) и просто добавь вторую строку fmt.Println(...) под первой. Текст пиши в двойных кавычках.

Go · task1.go
package main

import "fmt"

func main() {
    // первая строка — приветствие
    fmt.Println("Привет, мир!")
    // вторая строка — моё имя (замени на своё!)
    fmt.Println("Меня зовут Аня")
}
2

«Сумма двух чисел» ⭐

Создай две переменные с числами (например 7 и 5), посчитай их сумму в третьей переменной и выведи результат на экран.

Переменную создаём через := — например a := 7. Go сам поймёт, что это целое число (int). Сумма: sum := a + b.

Go · task2.go
package main

import "fmt"

func main() {
    a := 7        // первое число
    b := 5        // второе число
    sum := a + b  // сумма

    fmt.Println("Сумма:", sum) // выведет: Сумма: 12
}
3

«Привет, пользователь» ⭐

Спроси у пользователя имя, считай его через fmt.Scanln и поздоровайся лично: Привет, Маша!

Сначала объяви переменную: var name string. Потом считай ответ: fmt.Scanln(&name). Знак & обязателен — он говорит «вот адрес, куда положить ответ».

Go · task3.go
package main

import "fmt"

func main() {
    var name string // пустая переменная для имени

    fmt.Print("Как тебя зовут? ")
    fmt.Scanln(&name) // ждём ответ пользователя

    fmt.Println("Привет,", name+"!")
}

Обрати внимание: fmt.Print не переводит строку, а fmt.Println — переводит. Знак + склеивает две строки, как в Python.

4

«Квадрат числа» ⭐

Считай с клавиатуры целое число и выведи его квадрат (число, умноженное само на себя). Например: ввели 6 → получили 36.

Для целого числа объяви var n int, считай его через fmt.Scanln(&n), а квадрат — это n * n.

Go · task4.go
package main

import "fmt"

func main() {
    var n int

    fmt.Print("Введи число: ")
    fmt.Scanln(&n)

    square := n * n // квадрат числа
    fmt.Println("Квадрат числа", n, "=", square)
}

5

«Конвертер температур» ⭐⭐

Считай температуру в градусах Цельсия и переведи в Фаренгейты по формуле F = C × 1.8 + 32. Пример: ввели 36.6 → получили 97.88.

Температура бывает дробной, значит нужен тип float64, а не int. Объяви: var c float64, считай: fmt.Scanln(&c). Важно писать 1.8 через точку, а не запятую.

Go · task5.go
package main

import "fmt"

func main() {
    var c float64 // градусы Цельсия (дробные!)

    fmt.Print("Введи градусы Цельсия: ")
    fmt.Scanln(&c)

    f := c*1.8 + 32 // формула перевода

    fmt.Println(c, "°C =", f, "°F")
}
6

«Чёт или нечёт» ⭐⭐

Считай целое число и выведи чётное или нечётное. Используй if / else и остаток от деления %.

Если n % 2 == 0 — число делится на 2 без остатка, значит оно чётное. Обрати внимание: в Go условие пишется без круглых скобок, но обязательно с фигурными: if n%2 == 0 { ... }.

Go · task6.go
package main

import "fmt"

func main() {
    var n int

    fmt.Print("Введи число: ")
    fmt.Scanln(&n)

    if n%2 == 0 {
        fmt.Println("чётное")
    } else {
        fmt.Println("нечётное")
    }
}
7

«Таблица умножения» ⭐⭐

Сначала выведи таблицу умножения для числа 7 (7×1=7, 7×2=14 … 7×10=70). Потом улучши программу: пусть число вводит пользователь.

Цикл выглядит так: for i := 1; i <= 10; i++ { ... }. Три части через точку с запятой: старт, условие продолжения, шаг. Внутри печатай n * i.

Go · task7.go
package main

import "fmt"

func main() {
    var n int
    fmt.Print("Для какого числа таблица? ")
    fmt.Scanln(&n)

    // цикл от 1 до 10 включительно
    for i := 1; i <= 10; i++ {
        fmt.Println(n, "x", i, "=", n*i)
    }

    // а вот та же таблица для 7, без ввода с клавиатуры:
    for i := 1; i <= 10; i++ {
        fmt.Println(7, "x", i, "=", 7*i)
    }
}
8

«Средний балл» ⭐⭐

Считай три оценки (например 4, 5, 4) и выведи средний балл. Вспомни про целочисленное деление — иначе вместо 4.33 ты получишь 4!

Если делить int на int, Go отбрасывает дробную часть. Чтобы получить дробный ответ, преврати сумму в float64: float64(sum) / 3. Три числа можно считать одной командой: fmt.Scanln(&a, &b, &c).

Go · task8.go
package main

import "fmt"

func main() {
    var a, b, c int // три оценки сразу

    fmt.Print("Введи три оценки через пробел: ")
    fmt.Scanln(&a, &b, &c)

    sum := a + b + c
    // ВАЖНО: превращаем целое в дробное,
    // иначе (4+5+4)/3 дало бы 4, а не 4.33
    avg := float64(sum) / 3

    fmt.Println("Сумма:", sum)
    fmt.Println("Средний балл:", avg)
}

9

«FizzBuzz» ⭐⭐⭐

Выведи числа от 1 до 20, но: если число делится на 3 — печатай Fizz, если на 5 — Buzz, а если и на 3, и на 5 — FizzBuzz. Это самая известная задача на собеседованиях!

«И» по-гошному — &&. Порядок проверок важен: сначала проверяй оба делителя (FizzBuzz), и только потом по одному. Иначе до FizzBuzz дело никогда не дойдёт.

Go · task9.go
package main

import "fmt"

func main() {
    for i := 1; i <= 20; i++ {
        if i%3 == 0 && i%5 == 0 {
            fmt.Println("FizzBuzz") // делится и на 3, и на 5
        } else if i%3 == 0 {
            fmt.Println("Fizz")
        } else if i%5 == 0 {
            fmt.Println("Buzz")
        } else {
            fmt.Println(i) // обычное число
        }
    }
}
10

«Угадай число» ⭐⭐⭐

Загадай число константой (например 42). Пользователь вводит свои попытки, а программа подсказывает «Моё число БОЛЬШЕ» или «МЕНЬШЕ», пока он не угадает. В конце покажи количество попыток. Для ввода используй bufio.

Константа: const secret = 42. Бесконечный цикл: for { ... }, а выход из него — break. Строку в число превращает strconv.Atoi, а strings.TrimSpace убирает лишний Enter в конце.

Go · task10.go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    const secret = 42 // загаданное число
    attempts := 0      // счётчик попыток

    reader := bufio.NewReader(os.Stdin)

    fmt.Println("Я загадал число от 1 до 100. Угадай!")

    for { // бесконечный цикл, выйдем через break
        fmt.Print("Твоя попытка: ")
        line, _ := reader.ReadString('\n') // читаем строку до Enter
        line = strings.TrimSpace(line)

        n, err := strconv.Atoi(line) // строку -> в число
        if err != nil {
            fmt.Println("Это не число, попробуй ещё раз!")
            continue
        }

        attempts++

        if n < secret {
            fmt.Println("Моё число БОЛЬШЕ")
        } else if n > secret {
            fmt.Println("Моё число МЕНЬШЕ")
        } else {
            fmt.Println("Ура! Угадал за", attempts, "попыток(и)")
            break // выходим из цикла
        }
    }
}

line, _ := ... — знак _ означает «второй ответ функции мне не нужен, выбрось его».

11

«Перевёртыш» ⭐⭐⭐

Считай слово и выведи его задом наперёд: кот → ток. Сделай так, чтобы русские буквы не ломались (для этого нужен слайс рун).

Строку можно превратить в список букв: runes := []rune(word). Дальше иди циклом с конца в начало: for i := len(runes) - 1; i >= 0; i--. Длину узнаёт функция len().

Go · task11.go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strings"
)

func main() {
    reader := bufio.NewReader(os.Stdin)

    fmt.Print("Введи слово: ")
    word, _ := reader.ReadString('\n')
    word = strings.TrimSpace(word) // убираем Enter и пробелы по краям

    // превращаем строку в слайс рун,
    // чтобы кириллица не распалась на байты
    runes := []rune(word)
    reversed := ""

    for i := len(runes) - 1; i >= 0; i-- {
        reversed += string(runes[i]) // приклеиваем буквы с конца
    }

    fmt.Println("Наоборот:", reversed)
}

Есть и короткий вариант для любопытных: for _, ch := range word { reversed = string(ch) + reversed } — здесь каждая новая буква приклеивается спереди.

12

«Калькулятор» ⭐⭐⭐

Считай два числа и знак операции (+, -, *, /). Выполни действие через switch. Если пользователь делит на ноль — вежливо сообщи об ошибке, а не «урони» программу.

switch — это как if / elif / elif, только аккуратнее: switch op { case "+": ... default: ... }. Числа объяви как float64, чтобы деление было дробным. Проверку на ноль делай внутри ветки "/".

Go · task12.go
package main

import "fmt"

func main() {
    var a, b float64 // числа могут быть дробными
    var op string    // знак операции

    fmt.Print("Первое число: ")
    fmt.Scanln(&a)

    fmt.Print("Знак операции (+ - * /): ")
    fmt.Scanln(&op)

    fmt.Print("Второе число: ")
    fmt.Scanln(&b)

    switch op {
    case "+":
        fmt.Println("Ответ:", a+b)
    case "-":
        fmt.Println("Ответ:", a-b)
    case "*":
        fmt.Println("Ответ:", a*b)
    case "/":
        if b == 0 {
            fmt.Println("Ошибка: на ноль делить нельзя!")
        } else {
            fmt.Println("Ответ:", a/b)
        }
    default:
        fmt.Println("Не знаю такой операции!")
    }
}

Слайд 17 · Домашнее задание

Мини-проект: «Программа с меню»

Собери всё, что узнал, в одну программу. Она должна показывать меню, считывать выбор пользователя и выполнять нужное действие, а потом снова показывать меню — пока пользователь не выберет «выход».

1️⃣

Сложение

Пользователь вводит два числа через пробел, программа печатает сумму.

2️⃣

Таблица умножения

Пользователь вводит число, программа печатает таблицу для него.

3️⃣

Выход

Программа прощается и завершается.

🧰 Какие инструменты понадобятся

for { ... } — бесконечное меню · switch — выбор пункта · bufio — ввод строк · strings.Fields — разделить «5 7» на два числа · strconv.Atoi — строка в число · return — выйти из main.

Создай reader := bufio.NewReader(os.Stdin) один раз в начале и используй его для всех вводов. Внутри switch команда continue вернёт тебя к началу цикла (меню покажется снова), а return завершит программу.

Go · menu.go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    reader := bufio.NewReader(os.Stdin) // один «слухач» на всю программу

    for {
        fmt.Println("\n=== МЕНЮ ===")
        fmt.Println("1 - сложение двух чисел")
        fmt.Println("2 - таблица умножения")
        fmt.Println("3 - выход")
        fmt.Print("Выбери пункт: ")

        line, _ := reader.ReadString('\n')
        choice := strings.TrimSpace(line)

        switch choice {
        case "1":
            fmt.Print("Введи два числа через пробел: ")
            line, _ = reader.ReadString('\n')
            parts := strings.Fields(strings.TrimSpace(line)) // "5 7" -> ["5","7"]

            if len(parts) < 2 {
                fmt.Println("Нужно ввести два числа!")
                continue // возвращаемся к меню
            }

            a, _ := strconv.Atoi(parts[0])
            b, _ := strconv.Atoi(parts[1])
            fmt.Println("Сумма:", a+b)

        case "2":
            fmt.Print("Для какого числа таблица? ")
            line, _ = reader.ReadString('\n')
            n, err := strconv.Atoi(strings.TrimSpace(line))
            if err != nil {
                fmt.Println("Это не число!")
                continue
            }
            for i := 1; i <= 10; i++ {
                fmt.Println(n, "x", i, "=", n*i)
            }

        case "3":
            fmt.Println("Пока! Приходи ещё 👋")
            return // завершаем программу

        default:
            fmt.Println("Такого пункта нет, попробуй ещё раз")
        }
    }
}
